## 移动用户VPS推荐的第一步：先搞清 CMI、CMIN2、AS9929 分别是什么

移动用户选 VPS 比电信、联通麻烦，麻烦在移动的国际出口只有一条主干，商家有没有在这条主干上单独接线，决定了你打开网页是 30ms 还是 300ms。

移动的国际流量走 CMI，也就是 China Mobile International，AS 号 AS58453，这家公司 2010 年成立，总部在香港。判断一台 VPS 有没有接 CMI 有个很直接的办法：路由测试里出现 223.120.X.X 或 223.118.X.X 的节点，就是走了 CMI。买之前跟商家要一个测试 IP，自己 tracert 一遍，比看页面上写的“三网优化”四个字靠谱得多。

档次上分三层。CMIN2 是移动的精品网，定位和电信的 CN2 GIA 对标，移动方向最高端的一档；CMI 是标准国际线路，比 CMIN2 低一档；再往下是普通国际带宽，也就是大部分便宜 VPS 的实际水平。另外还有 AS9929，那是联通的精品网，部分网络架构下移动也能走到，三网回程走 9929 的产品，移动用户体验不算差。

最常见的坑是“号称三网优化，实际只优化了电信”。这类机器电信过去 30ms，移动绕一圈 300ms 以上，商家页面照样写“三网直连”。香港机房正经的做法是三条路各走各的：电信走 CN2、联通走 9929、移动走 CMI 或 CMIN2，谁也不挤谁。

## 六六云的线路盘点：香港 CMI、美西 9929、三网 CN2 GIA，缺一条 CMIN2

六六云手上对移动用户真正有用的线路有三条，外加一条大带宽路线，但它们对移动的友好程度差得挺远。

香港 CMI 系列是最对症的一条。第三方测评把回程路由完整贴出来了：从香港出发，经 223.119.81.125、223.120.3.85、223.120.2.41 三个 AS58453 节点，落到上海移动的 223.120.3.174，全程 30ms 左右；到北京移动走 221.183 段，43–46ms。同一台机器回上海电信走的是 59.43 开头的 CN2 节点，25–30ms。这就是前面说的“三网各走各的”，移动那段没被落下。

美西 9929 是第二选择，200Mbps、1 核 1G、1TB 流量、55 元/月。9929 的优势在联通，移动方向能不能吃到这条线要看具体路由，不像香港 CMI 那样一眼能确认。

美西三网 CN2 GIA 大带宽的主场是电信，200Mbps、800GB 流量、55 元/月，移动走的是 CN2 的回国路由，能用，但没有 CMI 那么对症。官方对这条线有一条说明值得记下来：不保证 ISP 属性，只是换了全新 IP 段。想拿它当住宅 IP 做账号的，得先想清楚这一点。

美西 4837 是纯拼带宽的路线，1Gbps 口子、1TB 流量、50 元/月，跑下载、做中转合适，谈延迟就没什么优势。

缺的那条叫 CMIN2。认准移动精品网的读者，六六云目前给不了，这是它在这条赛道上的空白。

## 常见问题

### 六六云有 CMIN2 线路吗？

没有。它的移动相关线路是香港 CMI，以及美西的 CN2 GIA、9929、4837。CMIN2 是移动精品网，比 CMI 高一档，六六云目前没有这条产品线，想要 CMIN2 双程的得换别家。

### 香港和美西同一个价，差价值不值？

不是差价的问题，是同价。香港 CMI-150M 和美西三网 CN2 GIA 都是 55 元/月，香港给 150Mbps、800GB、延迟 30–45ms，美西给 200Mbps、800GB、延迟按美国方向的常规水平。选香港买的是延迟，选美西买的是 50Mbps 带宽和落地位置。做站、日常访问选香港，跑业务、要美国 IP 选美西。

### 香港那档 50Mbps 的够用吗？

个人博客、小型企业站、几个人同时访问，50Mbps 够。要放图片、视频，或者同时在线的人多，直接上 150Mbps 那档，5 元的差价不值得省。

### 双 ISP 和原生 IP 差在哪，做 TikTok 该选哪个？

双 ISP 指的是 IP 在数据库里同时带两条运营商属性，比单 ISP 更接近家宽；原生 IP 指的是 IP 归属地真实。六六云的双 ISP 系列标的就是这个属性，但同一系列不同 IP 段在平台侧的表现差别不小。做账号的，下单前让客服把当前 IP 段说清楚，别只看商品名。
